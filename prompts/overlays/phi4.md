# OVERLAY — PHI-4

Applies to: `phi-*`.

- Terse by nature and template-friendly. It complies extremely well with
  short, explicit, format-heavy instructions.
- Give the output template and let it fill it. Avoid long narrative sections.
- Phi responds well to numbered steps and short imperative lists — compress
  multi-clause directives into numbered items.
- Do not expect Phi to infer the output format from a description; it needs
  the literal template.
- Full fidelity is unnecessary here — the kernel form plus one template per
  output class is the correct configuration for Phi-4.
